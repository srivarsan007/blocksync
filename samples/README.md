# BlockSync Sample Scenarios & Verification Commands

This directory provides a minimal self-contained scenario demonstrating BlockSync's constraint-satisfaction joint scheduling engine.

---

## Files in this Directory

1. `demo_tasks.csv`: The baseline 9-task cross-department backlog across Engineering, Signal & Telecom (S&T), and Traction Distribution (TRD).
2. `new_request.json`: A valid JSON payload ready for testing the `POST /tasks` API endpoint.
3. `expected_solver_output.txt`: The actual deterministic JSON output generated by executing `BlockOptimizerSolver` on `demo_tasks.csv` against `data/maintenance_windows.csv`.

---

## Copy-Paste Commands to Run the Samples

### 1. Run the CP-SAT Optimizer on `demo_tasks.csv`
```bash
python3 -c "
import json, pandas as pd
from optimizer.solver import BlockOptimizerSolver

tasks = pd.read_csv('samples/demo_tasks.csv')
windows = pd.read_csv('data/maintenance_windows.csv')

solver = BlockOptimizerSolver(tasks, windows)
schedule, status, _, trace = solver.solve()

print(f'Solver Status: {status}')
print(f'Tasks Scheduled: {len(schedule)} / {len(tasks)}')
print(f'Bundled Pairs: {trace.get(\"bundled_pairs\", [])}')
for e in schedule:
    print(f'  Task {e.task_id:3} -> {e.assigned_window_id} ({e.start_minute:3d}m - {e.end_minute:3d}m) [Bundle: {e.bundle_group_id}]')
"
```

### 2. Submit `new_request.json` via cURL to the Backend API
First ensure the backend is running (`uvicorn backend.main:app --port 8000`), then in a separate terminal:
```bash
curl -X POST http://127.0.0.1:8000/tasks \
  -H "Content-Type: application/json" \
  -d @samples/new_request.json
```
Expected response:
```json
{
  "id": "E5",
  "department": "Engineering",
  "section_id": "A",
  "duration_minutes": 45,
  "criticality": 4,
  "due_date": "2026-09-05",
  "status": "pending",
  "description": "Urgent sleeper packing & track alignment check"
}
```
